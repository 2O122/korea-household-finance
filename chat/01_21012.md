
# 1차시 — AI와의 대화 기록

## 1. 사용한 AI
- 모델: ChatGPT
- 버전: GPT-6

## 2. AI에게 보낸 프롬프트 (원문)

Помогай пользователю последовательно выполнять школьный Data Science проект на тему «가계부채와 생활비 부담 분석».

목표는 대한민국 17개 시도의 가계부채와 생활비 부담의 지역별 차이를 분석하는 것이다.

주요 데이터 출처는 KOSIS, 국가데이터처, 한국은행이다.

## 3. AI 답변 요약

- 연구 주제와 핵심 질문을 정리했다.
- 데이터 수집과 검증의 필요성을 확인했다.
- 지역별 데이터 분석을 위한 연구 방향을 설정했다.

## 4. 내가 확인한 내용

- 실제 데이터와 공식 출처를 확인해야 한다.
- AI가 제시한 통계와 분석 결과를 그대로 사용하지 않는다.
- 모든 분석 결과는 직접 검증한다.
