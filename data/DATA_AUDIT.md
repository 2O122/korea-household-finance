
# 데이터 현황 및 품질 점검

## 1. 연구 목적

대한민국 17개 시도의 가계부채와 생활비 부담을 비교하고,
지역별 재정 부담 유형을 분석하기 위한 데이터베이스를 구축한다.

## 2. 현재 확보한 데이터

| 지표 | 기준 기간 | 현재 상태 |
|---|---|---|
| 가구당 평균 부채 | 2024년 3월 | 17개 시도 확보 |
| 가구당 연평균 소득 | 2023년 | 17개 시도 확보 |
| 지역별 가구부채 추이 | 2017~2025년 | 일부 지역만 확보 |
| 처분가능소득 | 2021~2025년 | 추가 수집 필요 |
| 소비지출 | 2021~2025년 | 추가 수집 필요 |
| 소비자물가지수 | 2021~2025년 | 추가 수집 필요 |

## 3. 데이터 품질 점검 항목

- 지역 구분이 17개 시도로 일치하는지 확인한다.
- 조사 기준연도와 실제 측정 기간을 구분한다.
- 금액 단위와 지수 기준을 확인한다.
- 결측값과 이상값을 별도로 확인한다.
- 개인 정보가 포함되어 있지 않은지 확인한다.
- 자료의 출처와 이용 조건을 기록한다.

## 4. 데이터 활용 시 주의사항

가구부채는 조사연도 3월 31일 기준이며,
소득과 지출은 조사연도 전년도 기준이다.

따라서 부채와 소득의 측정 기간이 동일하지 않음을
분석 과정에서 명시한다.

근사 DTI는 지역별 평균값을 이용한 분석용 지표이며,
개인별 공식 DTI 또는 DSR과 구분한다.
